## ✨ Sobre

O projeto foi criado para transformar momentos especiais em uma experiência digital moderna, elegante e emocional.

Além da interface responsiva e animada, o aplicativo também funciona como uma **PWA (Progressive Web App)**, permitindo instalação em dispositivos móveis e desktop.

---

## 💕 Funcionalidades

- ⏳ Contador de tempo juntos
- ❤️ Contagem regressiva para datas especiais
- 📅 Timeline de memórias
- 📸 Galeria de fotos
- 💬 Mensagens personalizadas
- 📱 Aplicativo instalável (PWA)
- 🎀 Interface responsiva e animada

---

## 📱 PWA

O aplicativo pode ser instalado como um app nativo:

- Android
- iPhone
- Windows
- macOS

Também possui:
- cache inteligente,
- carregamento rápido,
- suporte offline parcial,
- experiência otimizada para mobile.

## ⚙️ Instalação

```bash
# Clone o projeto
git clone https://github.com/NCristofe/23-08-2026.git

# Entre na pasta
cd 23-08-2026

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```
