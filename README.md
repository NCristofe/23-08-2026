# 💖 Nosso App Romântico

<p align="center">
  <b>Um app para guardar momentos, memórias e o tempo que vivemos juntos.</b>
</p>

<p align="center">
  <i>Feito com React + amor + um pouco de obsessão por detalhes.</i>
</p>

---

## ✨ Sobre o projeto

Este é um app romântico moderno com foco em experiência visual e emocional.

Ele transforma datas e momentos em uma interface bonita e interativa.

---

## 💕 Funcionalidades

- ⏳ Contador de tempo juntos (desde 23/08/2025)
- ❤️ Contagem regressiva para 1 ano juntos
- 📅 Linha do tempo de memórias
- 📸 Galeria de momentos
- 💬 Mensagens especiais
- 🎀 Interface animada e responsiva

---

## 🎬 Experiência do app

O projeto não é estático — ele tem movimento e vida:

- Transições suaves entre telas
- Animações com Framer Motion
- Elementos aparecendo com fade e slide
- Interações leves ao navegar
- Design focado em sensação emocional

---

## 🚀 Tecnologias

- React ⚛️  
- TypeScript 🟦  
- Vite ⚡  
- Tailwind CSS 🎨  
- Framer Motion 🎬
