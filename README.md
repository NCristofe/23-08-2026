## ✨ Sobre o projeto

Este é um aplicativo romântico moderno desenvolvido para transformar momentos especiais em uma experiência visual interativa e emocional.

Além de funcionar como um site responsivo, o projeto também foi configurado como uma **PWA (Progressive Web App)**, permitindo instalação em dispositivos móveis e desktop como um aplicativo real.

---

## 📱 PWA — Progressive Web App

O app pode ser instalado diretamente no celular ou computador.

### Recursos PWA

- 📲 Instalação no Android, iPhone e Desktop
- ⚡ Carregamento rápido
- 📡 Estrutura preparada para cache offline
- 🖥️ Experiência semelhante a app nativo
- 🔔 Suporte moderno para experiência mobile

---

## 💕 Funcionalidades

- ⏳ Contador de tempo juntos (desde 23/08/2025)
- ❤️ Contagem regressiva para 1 ano juntos
- 📅 Linha do tempo de memórias
- 📸 Galeria de momentos
- 💬 Mensagens especiais
- 🎀 Interface animada e responsiva
- 📱 Instalação como aplicativo (PWA)

---

## 🎬 Experiência do app

O projeto foi pensado para transmitir emoção através da interface:

- Transições suaves entre telas
- Animações com Framer Motion
- Elementos aparecendo com fade e slide
- Navegação leve e fluida
- Design focado em estética romântica
- Experiência otimizada para mobile
